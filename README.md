# Mastery SMP - Resource Pack

The resource pack for the **Mastery SMP** server (Java Edition **1.21.11**):

- the Master Sword and the Leviathan Axe models and textures
- the core shader for the slash, sigil, beam, sky, rift, cleave, wraith and timer effects
- the HUD font

## Playing on the server

You don't need to do anything. The server offers this pack when you join; accept it.

## Installing it yourself

Download **[MasteryPack.zip](https://github.com/seeedey/MasterySMP-Pack/releases/latest/download/MasteryPack.zip)**
and put it in your `.minecraft/resourcepacks` folder, then enable it under **Options → Resource Packs**.

The pack replaces the `rendertype_item_entity_translucent_cull` core shader. If another pack you use also replaces
it, only the one higher in the list will work. Iris shader packs bypass core shaders, so the effects won't draw.

## How releases are made

Every push to `main` runs `.github/workflows/release.yml`, which zips the pack and publishes it as a new release
marked *latest*, with its sha1. The pack is generated by the plugin's private build tools and pushed here, so edits
made directly in this repo are overwritten by the next publish.
